# Data Analysis with R

A collection of R-based data analysis and statistical modelling work.

## Topics covered
- Exploratory data analysis and visualization with R, ggplot2 and Shiny dashboards for gas-distribution data.
- Multiple linear regression for the maximum-ozone (maxO3) response.
- Iterative backward variable selection and model summaries.
- Residual diagnostics and model plots.
- Shapiro-Wilk normality checks and non-parametric tests (Kruskal-Wallis and Wilcoxon) for categorical predictors.

## Source files
- Multiple_Linear_Regression_submission.R — R code for the maximum-ozone regression and statistical testing exercise.

## Input data
The supplied regression script prompts the user to select the source data table interactively. That input data file was not included with the uploaded source, so this repository does not publish numerical results or claim a reproduced model evaluation.

## Tools
R, ggplot2, Shiny, linear regression and non-parametric statistical tests.

# CIFAR-10 Image Classification and Optimization

A TensorFlow/Keras experiment using CIFAR-10 to compare model training and regularization choices.

## Included methods
- CIFAR-10 loading and train/validation split.
- Image augmentation (rotation, horizontal flip and brightness changes).
- Dense neural-network baselines.
- Batch normalization and dropout regularization.
- SGD optimizer and training callbacks.
- Accuracy/loss curves and confusion-matrix evaluation.

The notebook source was exported to a Python script. Model metrics are not included because they were not independently rerun during publication.

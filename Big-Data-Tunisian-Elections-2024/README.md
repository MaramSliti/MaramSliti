# Big Data Analytics – Tunisian Elections 2024

Academic Big Data Analytics project exploring Tunisian 2024 election data with a distributed data-processing workflow.

## Evidence and scope
The uploaded project archive contains screenshots documenting:
- A MySQL database named `elections_tunisie_2024`
- Importing relational data from MySQL into Hadoop Distributed File System (HDFS) using Apache Sqoop
- Creating and querying Hive tables
- Working with election-related entities including candidates, districts, electors, observers and results

## Technologies
- MySQL
- Apache Sqoop
- Hadoop / HDFS
- Apache Hive

## Repository contents
This repository currently documents the project and its verified technical scope. The supplied archive contains screenshots and course material, but no original project source scripts or database dump. No source code or election dataset is represented as included.

## Academic project
The screenshots and project description are based on the material supplied for portfolio documentation. This repository is a project overview, not a claim of a complete reproducible implementation.

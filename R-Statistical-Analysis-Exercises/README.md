# Statistical Analysis Exercises (R)

A collection of R coursework code for regression and statistical inference.

## Included
- Multiple linear regression for the maximum-ozone response (maxO3).
- Backward variable removal and model diagnostics.
- Residual plots, Shapiro-Wilk checks and non-parametric comparisons for categorical predictors.

The provided R script expects the source table to be selected interactively. The input data file was not part of this upload, so numerical results are not reproduced here.

# Neo4j Graph Database Study

Academic study notes from the supplied Neo4j document.

## Topics
- Nodes, relationships and properties in graph databases.
- Cypher create, read, update and delete operations.
- Native graph storage, indexes and architecture layers.
- ACID transaction management, Bolt protocol and caching.
- Causal clustering, Raft and read replicas.
- Graph traversal, path finding, pattern matching and relationship analytics.

The source is a study/presentation document, not a runnable Neo4j application; no database dump or executable Cypher project was supplied.

# Economic Time-Series Analysis (R)

R notebook work supplied in the Time Series folder, consolidated as R scripts with notebook outputs removed.

## Analysis covered
- Job openings and economic/industrial production series.
- Monthly retail garden-equipment sales and wood exportation series.
- Time-series construction, graphical and seasonal analysis.
- Trend/seasonal decomposition, ACF/PACF and stationarity testing.
- ARIMA modelling and regression with structural breakpoints.

## Files
- TimeSeriesProjectPhase1and2_1.R — multi-series analysis.
- TimeSeries_Final_Assessment.R — project assessment workflow.
- Lab3_TimeSeries.R — breakpoint and regression exercise.
- Autocorrelation_Adjustment.R — autocorrelation and decomposition exercises.

The source notebooks reference additional spreadsheets which are not replicated here. Put the corresponding source workbooks beside the scripts before running them.

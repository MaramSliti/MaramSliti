# Property Rental and Appointment Management — Java

A Java academic-project sample containing repository-layer logic for rental listings and appointments.

## Included classes
- LogementRepository: in-memory listing storage, filtering by type and lookup by reference.
- RendezVousRepository: in-memory appointment creation, update, filtering, lookup and deletion.

Only these two repository classes were present in the supplied files. Entity classes, the application/UI and persistence layer are not included, so this is a code sample rather than a complete runnable application. Hard-coded addresses and phone numbers from the original sample were replaced with neutral examples.
